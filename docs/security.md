# セキュリティ

[目的別ガイド](../README.md) / [設定仕様](reference.md) / [復旧](recovery.md)

## 実行ユーザーと接続

```text
公開Apache（pjas-apache）
  → 管理用HTTP（127.0.0.1:8184）
    → 管理用FPM（pjas-control）
      → Unixソケット → 特権agent（root）
```

管理画面はrootでは動きません。rootのagentが要求の種類、対象サイト、パス、状態、コマンドを検査します。Webは認証・CSRF・利用者とサイト範囲の権限を確認し、重要操作で現在のパスワードと必要な再認証を求めます。

通常サイトはサイト専用ユーザー、処理別構成は処理ごとの専用ユーザーを使用します。Apacheの実行ユーザーとPHPを分離し、専用FPMソケットへ必要な接続権だけを付けます。未移行の共通ユーザー構成は既存環境の互換動作で、新規サイトの標準ではありません。

## コード・データ・秘密情報

- コード・設定・Gitメタデータはroot管理とし、サイトや管理画面のPHPから変更できない状態を維持します。
- 実行ユーザーにコードの書き込み権を与えず、書き込み先を`shared`または割り当てた永続領域へ限定します。
- サイト間・処理間でUID、GID、補助グループ、書き込み領域を共有しません。
- 公開フォルダ外の設定・DB・秘密情報を、URLから取得できる場所へ置きません。
- アーカイブのパストラバーサル、リンク、特殊ファイル、許可しないハードリンクを拒否します。ハードリンク修復の条件は[復旧](recovery.md)を参照します。
- GitHub App秘密鍵・一時認証情報・通知URL・バックアップ鍵・レビューはroot管理領域へ保存します。認証情報をGit URL・コマンド引数・作業ログへ埋め込みません。

管理用RPCグループへ本番サイトのユーザーを追加しません。Web設定の`security_key`を失うと、暗号化した二段階認証情報等を復旧できないため、DBと対応付けて保護します。

## ctrl自身の更新

更新元とブランチはrootが登録します。更新元リポジトリのコードはサーバー上で実行されるため、そのリポジトリへの書き込み権限・GitHub Appの管理権限は重要な信頼境界です。

画面から変更できるのは、rootが確認した更新レビューの適用要求だけです。任意URL・ブランチ・コミット・コマンド・配置先を渡せません。固定コミット、有効期限、現在のコード・設定、fast-forward、ローカル変更、ファイル種別を検査します。private取得には対象リポジトリ限定・Contents読み取りの一時トークンを使い、終了時に一時ファイルを削除します。

管理画面と別の更新サービスが処理を続けます。更新中は通常のWeb・CLI書き込みと新しいagent操作を止め、PHP・監視等を停止して管理DBを保存します。HTTP検査用の一時認証情報はroot側に保持します。更新サービス全体のumaskは0077を維持し、更新したGit管理下のコードだけを管理ユーザーのグループに0640・実行ファイルとフォルダに0750で公開します。設定・秘密情報・退避領域をこの権限変更に含めません。秘密のunit本文や生の認証エラーを画面へ表示しません。設定・サービス・更新基盤の変更は保守手順へ分けます。

## 監視の範囲

HTTP、登録済みサービス、証明書、保存領域、バックアップ、ログイン失敗、設定ファイルのハッシュ等を監視します。rootを奪われた場合の検知や、すべてのCVE・アプリの欠陥の検出を保証するものではありません。

SSH失敗は対応するjournalの直近10分・最大2000行を集計します。設定監視は最大1000ファイル・各1MBまでで、本文を保存せず、初回測定を基準にします。測定間に変更して元へ戻したものは検知できません。APTは保存済み一覧の確認であり、OS更新の自動適用ではありません。

サーバー全体が停止すると内部から通知できません。外部監視・別ホストへのバックアップ・鍵の保護を併用してください。

## 隔離の限界

この構成は1台のOS上のユーザー・ファイル権限・systemd制限による分離です。rootやカーネルからの完全な隔離ではありません。許可した公開後処理・常駐コマンドは、そのユーザーが読めるデータへアクセスできます。管理者が許可台帳・環境変数・追加設定で与えた権限の影響も確認してください。

コードを戻してもDB・共有データは戻りません。CA状態の復元では発行・失効履歴の欠落や外部署名処理の二重稼働を、利用エンジン側の検査で確認する必要があります。ctrlはCAエンジンやクラスタ排他機構を提供しません。
