# サイト削除機能の追加検証（2026-11-03）

緊急反映時に中断した追加検証を再開し、次を確認しました。

- 36本のPHP回帰テストが成功（35本の通常テストと、HTTP通信を使うサイト停止テスト）。
- PC幅1440px・スマートフォン幅390pxで削除画面を表示し、横にはみ出さないことを確認。
- サイト名の入力違い・パスワード違いでは削除しない。
- 画面から削除→復元を実行でき、管理解除では元のコードを保持する。
- ctrl自身の削除、閲覧者の削除画面へのアクセス、CSRFトークン不正を拒否する。
- 公開作業のロック中は削除を開始しない。
- 削除時の設定検査が失敗した場合は元の設定とデータを保持する。
- 復元時の設定検査が失敗しても退避データを失わず、再度復元できる。
- 復元先の同名フォルダを上書きしない。30日の期限後は復元を拒否し、退避データを消去する。
- 削除済みサイトを予約公開・GitHub Webhookによる自動公開の対象から除外する。

検証で、`demo`の参照確認が`demo-other`のパスにも一致する不具合を検出しました。パスの区切りまで確認する方式へ修正し、別サイトを誤検出しないことと、実際の参照は検出することをテストに追加しました。

ブラウザー検証は実際のPHPアプリ・SQLite・ファイル退避処理を使っています。Apache・systemdへの外部コマンドはテスト用の代替コマンドで成功・失敗を再現しました。本番サーバーへの適用、実際の常駐プログラムの停止・起動はこの検証には含みません。

更新する場合：

```bash
cd /opt/pjas-ctrl
sudo git pull --ff-only origin main
sudo -u pjas-control php8.4 bin/pjas-migrate
sudo systemctl restart pjas-agentd
sudo systemctl reload php8.4-fpm
```
