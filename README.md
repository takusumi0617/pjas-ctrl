# pjas-ctrl

1台のUbuntuサーバーで、PHP・静的サイトの公開、実行環境、監視、バックアップを管理します。新規サイトは専用ユーザーで隔離し、PHP 8.5を既定にします。複数の処理を持つサイトは、処理別のユーザー・永続領域・秘密情報を割り当てられます。

標準環境はUbuntu 24.04、Apache 2.4、PHP 8.5、systemdです。PHP 8.6は実行環境の追加先として扱い、導入とアプリの互換性確認後に選択します。

日常操作は管理画面のサイト詳細へ集約しています。ctrl自身の更新はホームから確認・実行できます。GitHub App連携済みなら、許可されたprivateリポジトリも利用できます。初回の更新サービス登録はサーバー管理者が行います。

コードの切り戻し、共有データの復元、CA状態の復元は別の操作です。運用前に[復旧ガイド](docs/recovery.md)で、それぞれが戻す範囲を確認してください。
