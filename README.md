# pjas-ctrl

PHP・静的サイトの登録、デプロイ、Apache設定、監視、バックアップを、1台のLinuxサーバーでまとめて管理するコントロールプレーンです。

管理画面は専用の `pjas-control` ユーザーで動きます。ファイル配置やサービス操作などの特権処理は、rootで動く `pjas-agentd` が検証して実行します。

## 導入の前提

標準の導入手順は **Ubuntu 24.04 / PHP 8.5 / Apache 2.4 / systemd** を対象にしています。PHPコード自体の最低要件は8.1ですが、付属の初回準備コマンドとサービス定義はPHP 8.5を前提にします。

管理画面用のDNS・HTTPS証明書・アクセス元制限を用意してください。必要パッケージと配置先は [新規導入](docs/install.md) に記載しています。pjas-certのCAエンジンや鍵の生成は、ctrlの通常インストールには含みません。

## 公開とデータの扱い

通常サイト（v1）は `releases` にコードを配置し、確認後に `current` を原子的に切り替えます。DBやアップロードなどは `shared` で引き継ぎます。コードを切り戻しても、共有データやDBの構造は元に戻りません。

専用ユーザーが必要なサイト（v2）は、管理者が事前に許可したプロファイル・永続領域・秘密情報を参照します。設定更新、コード公開、初期化、CA状態の復元をそれぞれ明示して実行します。

通常サイトは共通の実行ユーザーを利用します。管理画面と本番サイトの分離、v2の隔離範囲、root管理者を含む信頼境界は [構成と権限](docs/architecture.md) を参照してください。

新規サイトは専用ユーザー・サイト別FPMで隔離し、PHP 8.5を既定にします。既存サイトとPHP 8.6への更新は[隔離・PHP移行ガイド](docs/site-isolation.md)を参照してください。
